## 官方公共变化

- 修复跨 Anthropic / Responses / Chat 协议转换的缓存创建、读取及 TTL 统计，渠道可配置 Ultrafast 倍率。
- 流式空闲超时按照最后一次上游读取计时；首个模型输出前的超时进入已有的一次安全切换预算，输出后不重放。原生 Chat SSE 在下一次上游读取前合并刷新。
- 增加 GPT-6.2 Sol / Astra 元数据、别名与 Ultrafast 权限识别。
- 新迁移 `252_channel_pricing_ultrafast_multiplier.sql` 只增加可空倍率列及约束；未设置时沿用既有倍率，不批量改写账号或渠道配置。

这些是官方公共代码的升级，不能表述为所有公共调度、计费代码完全没有变化；SIWC 专属流程保持，公共变化通过兼容回归和正式使用记录核验。
