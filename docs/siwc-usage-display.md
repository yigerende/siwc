# SIWC 用量窗口（2026-11-13）

SIWC 使用普通账号同一 UsageProgressBar 展示请求数、Token、A 账号费用、U 用户费用、7d 使用率、重置倒计时和预计总费用。真实 5h 不存在时显示「5h：未提供」；没有任何成功查询则显示待查询。取消原先额外 SIWC 额度区和空横杠。

百分比与重置时间只来自匹配当前 SIWC app_id 的 siwc_usage 快照，不探测普通 Codex 接口、不制造缺失窗口。费用由本站 usage_logs 统计，区间为 [reset_at - window_seconds, checked_at)，A 沿用账号费用和倍率，U 沿用用户实际费用。因此上游刷新失败不会继续把新费用除以上次百分比；保留原成功窗口、统计截止时间和错误。统计读取失败不伪造零成本。成功样本过期会标记等待刷新。

预计总费用 = 同一 7d 窗口账号费用 × 100 / 使用率，原值计算、显示两位小数。零使用率、零费用、缺失/无效统计或已过期窗口显示「暂不可估」。该值为估算，不是上游承诺的总额度。

列表复用原当前页批量读取与缓存、移动端可见时加载。SIWC 单账号刷新先 POST /api/v1/admin/siwc/accounts/:id/usage，再强制重新读取对应窗口统计；批量请求版本避免旧响应覆盖。移动端请求按账号及请求版本校验，翻页后迟到响应不得写到另一个账号。没有增加逐行自动轮询、数据库迁移或业务设置。

Space 预计支撑公式不改；普通账号刷新及配额重置入口不改，SIWC 不显示普通 Codex 重置入口。

验证：本地 SIWC service、repository 时间上下界回归通过；前端 85 项相关回归通过（SIWC 单/双窗口、0%、失败保留、过期、刷新路由、切换账号、原普通展示），类型检查、生产构建、Go vet 通过。真实组件在 1440px / 390px 浏览器检查，无页面异常。正式镜像另执行 Linux 同组后端回归，正式读取验证另记运维 runbook。
