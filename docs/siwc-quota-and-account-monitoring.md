# SIWC 额度、复核和账号观察（2026-11-12）

网页额度按 app/client ID 定位唯一应用，接受上游实际返回的5h和/或7d窗口。不存在的窗口为nil，页面显示未提供；仍拒绝重复窗口、无效百分比/重置时间、空窗口和歧义应用。不再显示无成功时间的公元1年，不显示普通OAuth的占位0%额度。

Space 在额度步骤重新网页登录并更新原账号两个网页凭证字段后，可调用现有POST usage刷新；读额度继续GET。SIWC推理凭证与网页凭证分离。

账号管理移植 Qerkai RPM 与最近请求实现。RPM是最近60秒业务请求开始次数，按请求/账号去重，同账号传输重试不重复计数，切号各自计数，WS逐轮计数。只作显示，不更改调度限额；内存计数、每秒Redis批量累计快照，失败重送不叠加；空闲过期，跨实例汇总。列表仅批量读当页账号，无法读取显示--。

最近请求列读取当页每账号最近10条，usage/ops错误按request_id去重，成功恢复显示绿条，最终失败红条，时间及脱敏错误摘要供悬停查看。索引有界查询、最多100个账号/批、两路并发门限、5秒查询上限；不读请求正文、不扫描全历史，不独立新增页面定时器。页码/筛选切换取消旧请求，隐藏列停止查询。

单账号POST /admin/accounts/{id}/test兼容自定义prompt与reasoning_effort；test_start携带custom_prompt和实际effort，完整结束返回test_complete。SIWC账号按绑定代理经过原SIWC插件通道；代理缺失或插件未就绪失败，不回退普通OAuth；复用SIWC token provider续期能力。未修改Space现有质量判定和SIWC自动质量监控规则。
