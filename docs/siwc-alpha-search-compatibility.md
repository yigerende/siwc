# SIWC 联网搜索兼容

账号管理顶部的「SIWC 联网搜索兼容」默认关闭，保存后当前实例立即生效，重启保留。仅选中 SIWC 账号的独立搜索请求受它控制。

- 关闭：继续原来的 `/alpha/search` 路径，普通模型请求也保持原样。
- 开启：将客户端 `/v1/alpha/search` 的搜索任务转换成 `/v1/responses`，使用 SIWC 已支持的 `web_search` 工具，通过原 SIWC 插件、账号凭证及代理发出。返回客户端仍是独立搜索的 JSON 格式。
- 普通 OAuth、API Key、PAT 和普通 `/responses` 请求不由本开关改写；原来的工具检索、远程压缩开关各自独立。

完整保留搜索命令、上下文及位置、域名、外网访问等设置，不按字符截断命令。搜索、打开网页、查找文字由 hosted web_search 执行；返回标题、网址及最终结果。引用用完整网址作为 `ref_id`，供后续 open/find 使用，不依赖某个账号、进程内缓存或虚构的加密搜索状态。

这是 Responses 联网搜索适配，不代表 SIWC 获得了原生 alpha/search 权限。专用图片搜索、截图、金融/体育等 alpha 命令没有获得相同专用工具能力，模型必须如实说明不能完成的操作；也无法解密旧原生接口的 `encrypted_output`。跨到此路径的历史搜索应使用完整 URL 或重新搜索。

只有收到完整成功终态、实际执行了 web_search 并有结果文本才返回成功。仅 HTTP200、部分文本或 `[DONE]` 不算成功。响应大小沿用既有上限，客户端断开沿用原请求取消。流内配额/临时错误交给现有故障转移分类；不新建调度或重试引擎。

使用原独立搜索按次计费：一次成功逻辑请求仍记一次，失败不生成成功计费结果。适配内部可能执行多个 hosted 搜索操作并消耗上游模型额度；不会另建一笔 Responses 用户扣费。

管理员接口：`GET/PUT /api/v1/admin/siwc/alpha-search`，请求/响应 `{ "enabled": false }`，持久设置键 `siwc_alpha_search_compat_enabled`。读取缓存 60 秒，保存与读取串行防止旧值覆盖；数据库异常保留已知配置，首次读取失败默认关闭。失败保存不会显示成成功。

测试覆盖：开关及账号类型隔离、原请求/原响应不变、长中文命令、域名/位置/外网设置、网址引用、SSE/JSON/缺 Content-Type、失败/断流/超限/取消、HTTP 错误、配额故障转移、并发隔离、持久保存以及原独立搜索计费回归。真实验收使用专门构造的公开信息搜索，不重放客户内容。
